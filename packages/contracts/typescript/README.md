# Generated browser contract client

Pydantic models in `packages/contracts/python` own wire shapes. Offline FastAPI declarations in `src/api` own HTTP operations. Run these from the workspace root:

```sh
pnpm install --frozen-lockfile
pnpm setup:workspace
pnpm contracts:check
pnpm format:check
pnpm lint
pnpm typecheck
pnpm build
```

`contracts:generate` validates OpenAPI 3.1, exports sorted JSON with a SHA-256 manifest, then generates Fetch SDK, Zod 4 validators, and TanStack Query v5 options. `contracts:check` requires local outputs from setup/generation, generates fresh output into a temporary directory, and compares file sets and bytes without changing the checkout; Git is not involved. Missing output produces an actionable setup/generation error; stale output requires `pnpm contracts:generate`. `packages/contracts/schemas/` and `src/generated/` contain ignored generated artifacts only. Do not hand-edit or commit them. `pnpm setup:workspace` runs frozen uv installation and generation after frozen pnpm installation; `pnpm typecheck` and `pnpm build` explicitly regenerate before compiling, without relying on pnpm lifecycle hooks. Future development/build/deployment commands must generate before consuming these imports, using the pinned generator and lockfiles. Generation uses local Pydantic/FastAPI metadata and does not contact a running API. The OpenAPI snapshot retains Python's deterministic JSON formatting so its digest identifies the exact generated bytes for that build.

The public entry point initializes the default validated transport. `createValidatedClient({ baseUrl, fetch })` creates an isolated client with the same validation. The public SDK validates its final result again after generated Fetch transformations and empty-body shortcuts, then resolves to the success envelope and throws `ApiError` for documented error envelopes or `ContractValidationError` for invalid requests/responses. JSON mode is fixed. Network/abort failures, including failures while reading a response body after headers arrive, retain their original error. Malformed JSON is a ContractValidationError. A configured response transformer, including one installed later through `client.setConfig`, must still return the canonical success envelope; invalid transformed data and the generated Fetch `Content-Length: 0` empty-object shortcut are rejected before Query can cache them. The raw generated SDK remains internal because its field-result error types describe server wire JSON, while transport errors are Error subclasses.

```ts
import {
  contractManifest,
  createValidatedClient,
  listRuns,
  listRunsOptions,
} from "@featherlane/contracts";

const client = createValidatedClient({ baseUrl: "http://localhost:8000" });
const request = {
  client,
  path: { projectId: "project_demo" },
  headers: { "x-flf-contract-version": contractManifest.contractVersion },
  query: { limit: 50 },
};
const envelope = await listRuns(request);
const options = listRunsOptions(request);
```

Public Query options use generated operation keys and disable automatic retries. Runs and run-options builders accept an optional scope prefix; P03 supplies the demo identity epoch, organization/project and scenario revision before the generated operation key. The feature composes the generated mutation options with the final-validating createRun SDK wrapper, uses fresh eligibility before submission, and retains an idempotency key for retries of an unchanged payload. A response interceptor selects the schema for the actual status before the SDK or Query resolves. Its route/status map is generated from OpenAPI. Errors with a 2xx status, success bodies with error statuses, non-JSON data, undocumented statuses, and unknown object fields are rejected. Validation messages omit submitted bodies. A safe response request ID is retained when present; request validation or network failures may have no request ID.

The pinned generator needs two configuration resolvers: preserve `additionalProperties: false` as Zod `.strict()`, and normalize Fetch `Headers` into lowercase plain keys for generated request validation. Python's header alias is lowercase because HTTP header names are case insensitive. The generated code passes strict TypeScript plus unchecked-index checking. `exactOptionalPropertyTypes` is not enabled because the pinned Fetch template does not compile with that additional flag; required-nullable wire semantics are enforced by both validators.

The offline declarations now cover metadata, filtered/cursor Runs lists, selected run options and idempotent run creation. RunListEntry adds display labels to RunSummary for the list; RunOptions carries runner/build/profile/published-suite choices, eligibility reasons and repetition bounds. The schema factory is for offline export, and its handlers deliberately raise if invoked. It is not a business API or an ASGI deployment target. Authentication, server compatibility enforcement, sanitized FastAPI exception handling, RunDetail, events, production pagination/admission, and other feature contracts belong to later phases. Feature query modules must add authenticated epoch/tenant scope and identity cleanup before production use. Only the fixture MSW transport is runnable now.

Generation sources: [Hey API SDK validation](https://heyapi.dev/docs/openapi/typescript/plugins/sdk#validators), [Zod generator](https://heyapi.dev/docs/openapi/typescript/plugins/zod), [TanStack generator](https://heyapi.dev/docs/openapi/typescript/plugins/tanstack-query), [FastAPI OpenAPI export](https://fastapi.tiangolo.com/how-to/extending-openapi/), and [Pydantic strict JSON validation](https://docs.pydantic.dev/latest/concepts/strict_mode/).

The workspace pins `js-yaml` 4.x consumers to patched 4.3.2 through a narrow pnpm override. The generator's original transitive 4.2.0 resolution triggered three high-severity dependency advisories; the patch remains within its major version. See the [upstream advisory and patched release](https://github.com/advisories/GHSA-2883-xcg3-v3hh). Generation and type checks passed with the override.
