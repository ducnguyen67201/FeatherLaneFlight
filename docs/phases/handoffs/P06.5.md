## Behavior and integration seam

- Public `getSession`/`logout` wrappers retain generated request/response Zod
  validation and actual-status typed errors. Query/mutation policy reuses
  generated keys/options; automatic retries stay disabled.
- Native Google navigation uses generated `browserNavigationPolicies`, separate
  from JSON operations. No JSON fetch is used to validate an OAuth redirect.
- Auth transport enforces application origin, same-origin cookies, cloned
  headers, current session-bound CSRF on mutations, no-store and redirect error.
  Session handles remain opaque/HttpOnly. No localStorage/persistent cache.
- Auth identity/CSRF changes retire the previous client, cancel outstanding
  reads, clear query and mutation caches and create a new QueryClient. Late
  responses abort and late callbacks guard their originating epoch. Logout hides
  children before network activity; uncertain failure stays locked, with guarded
  retry and fresh CSRF retrieval. A 401 clears identity. A 403/404 is not logout.
- `AuthBoundary` owns QueryClientProvider. Its authenticated render callback
  receives canonical `session`, epoch-bound `client`, `authEpoch`, auth-owned
  `cacheScope` (`["auth", authEpoch, userId]`), `onSignOut()`
  and `onSessionExpired()`. Feature children use `useQueryClient()` context.
  P07 owns actual discovery, membership decisions, user/org/project cache scope
  and access-change hiding/invalidation. Its actual export is required before
  normal-entry composition. Do not mount the fixed Runs demo as authorized access.
- Session rechecks occur on visible-page/focus return. There are no current
  application SSE streams; no speculative stream framework was introduced.
