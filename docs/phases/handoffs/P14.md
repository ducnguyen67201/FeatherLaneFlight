Actual exports:

- `Supervisor(store: StateStore, budget: DiskBudget)` owns the existing runner lock.
- `stop(reason: StopReason) -> StopResult`, including EVIDENCE_BUFFER_FULL.
- `snapshot() -> StopResult | None`, `recover() -> StopResult`.
- `closed_output() -> ClosedOutput`: confirmed exit/cleanup plus exact sealed-file
  identity/size/hash; readonly mode alone is not evidence.
- `remove_closed_output(closed: ClosedOutput | None = None) -> None`: only P14
  restores original directory write permission, removes exact owned files and
  releases after the entire reservation is absent. Retry handles interrupted
  removal; a consumer must not chmod/delete/release originals itself.

`StopResult` fields are attempt_id, generation, reason, process_exited, group_exited,
cleanup_confirmed and nullable exit_code. `ClosedOutput` carries that result,
directory and a tuple of local frozen `ClosedFileRecord` metadata. Consumers
must retain safe descriptor checks while reading and bind stop callbacks to their
active attempt. These exports grant no server lifecycle or evidence authority.

The common API is `reserve(id, attempt_id, kind, bytes)` and
`release(id, attempt_id)`, with its own nonblocking short ledger lock. Before any
child/output creation P14 reserves 128 EVIDENCE bytes bound to that exact attempt.
The parent remains 0700, nested output becomes 0500 and its single file 0400 after
exit; there are two contents within the four-content limit. The shared default
budget is logical 500 MiB = 64 events + 435 evidence + 1 accounting, max32
reservations. Original/copy peaks must be separately charged. No release happens
on process exit, expiry, upload acknowledgment or missing/crashed directories.

`standin.txt` is bounded supervision diagnostics only. It is not canonical
OBSERVATIONS, ULog, redacted flight evidence, qualified execution or a passing
result. stdout/stderr are DEVNULL. Identity/process records, closed metadata and
used-attempt markers are outside this managed logical evidence/event allowance;
there is no physical filesystem or whole-host quota claim.
