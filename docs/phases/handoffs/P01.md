## Completed scope

Added a minimum pnpm/uv workspace and canonical framework-free Pydantic package. The package owns the complete status vocabulary from §7.2, pinned contract/protocol versions, bounded success/error envelopes, required-nullable RunSummary fields, and bounded cursor list response. It rejects extra keys, alternate aliases, unknown enums/versions, incorrect primitive types, invalid UTC timestamps, and oversized lists. Timestamp strings remain strings across Python/TypeScript; the exported pattern also excludes year 0000 to match Python's datetime range.

Added an offline FastAPI schema factory declaring only `getContractMeta` and `listRuns` with stable operation IDs and custom ErrorEnvelope response metadata, including 422. Export validates OpenAPI 3.1, writes deterministic sorted JSON, and records SHA-256 provenance. The factory has no DB, auth, worker, runner, or simulator startup; its route functions deliberately raise if invoked. It is not the runnable P05 business API.

Generated Fetch SDK, TypeScript types, Zod 4 validators, and TanStack Query v5 options with pinned Hey API 0.99.0. Both generated request and response validation are explicitly enabled. Two schema-driven generator resolvers qualify the pinned version: `.strict()` for forbidden object extras, and plain lowercase header normalization from Fetch Headers before request validation. Generated files were not hand-edited.

The handwritten transport selects the documented validator for the actual response status using an OpenAPI-derived route/status map. Documented errors become ApiError; invalid requests/responses become ContractValidationError with a safe response request ID when available. Public SDK functions validate their final generated result against the success schema after transformations/empty-body shortcuts, then resolve to success envelopes and throw errors, avoiding misleading raw generated field-result error types. Body-read abort/network errors retain their original types; only malformed JSON SyntaxError becomes ContractValidationError. Public Query options use generated keys, validate before caching, and disable automatic retries.

Added one shared raw JSON queued-run fixture, validated metadata/empty/forbidden envelopes, and opt-in MSW handlers using generated operation paths and validators. A configurable delay supports later loading previews. No worker or browser interception starts on import. Added no application UI, automated tests, snapshots for tests, coverage configuration, or test scaffolding.
