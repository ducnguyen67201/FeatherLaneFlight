## Limitations and successor artifacts

Editors or ad-hoc imports that bypass setup can report missing generated modules; run `pnpm setup:workspace` first. `contracts:check` diagnoses local stale/missing output; it is not a Git-diff gate or a standalone CI/deployment implementation. Future dev/build integration must preserve generate-before-consume ordering. Direct Hey API invocation does not produce the custom policy map, so normal use goes through the complete `contracts:generate` pipeline.

The schema factory remains metadata-only. P05 still owns the runnable API and real request/response conformance, custom sanitized 400/422/500 handlers, and server version enforcement. Later phases own RunDetail, events/tagged unions, auth/session/CSRF and tenant cache scope, real pagination/mutations, runner execution, and PX4. The mock transport remains a deterministic one-page development fixture. No UI preview/approval applies to this foundation-only revision.
