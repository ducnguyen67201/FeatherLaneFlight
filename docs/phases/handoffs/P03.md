## Implemented scope

The approved Runs list and inset right-side New Run modal are implemented under `src/web/features/runs/`. The list uses generated SDK/Query options for server-filtered search/execution/outcome reads and cursor pages. Empty/loading/error states and explicit demo controls remain visible. The details Open action is disabled with a nearby explanation; P04 detail/evidence/cancellation screens are not implemented.

The five-step form reads canonical runner/build/profile/published-suite options and API-owned repetition bounds. Upstream changes clear dependent selections. New submissions refetch current eligibility; the MSW admission handler rechecks the runner/build/profile/suite/bounds too. Unconfirmed submissions retain an immutable original body/key and review snapshot; recovery replays that operation without an eligibility read. Editing is locked until a definitive outcome, and closing/reopening preserves recovery. Known rejections remain editable; unchanged payloads reuse their key and changed payloads receive a new one. Acknowledged mock creation adds only Queued / Not evaluated; no component timer advances execution or outcomes.

The modal consumes accepted geometry from canonical tokens, with fixed header/footer, internal scrolling, keyboard containment, idle Escape/backdrop/close behavior, pending-close protection, normal focus restoration and an empty-state-opener fallback. Panel geometry is scoped to this Drawer; navigation remains its original width.

Canonical Pydantic/HTTP metadata now covers list display labels, filters, run options and creation. Generated schema/client/validator/Query outputs remain ignored. Browser MSW starts before the current demo entry renders; its worker is regenerated by dev/build tooling and ignored. No live backend, runner, PX4, authentication, durable queue or script execution is connected.

The form is decomposed into a focused `useNewRunWorkflow` hook, typed setup-step components and a review component. `NewRunPanel` owns modal composition and focus. The human-requested AGENTS guidance is included in this candidate.
