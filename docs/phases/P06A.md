3. Add canonical session/logout/identity errors and authenticated principal/CSRF dependencies. Keep explicit service transactions and bounded sanitized HTTP errors from P05. Extend canonical contracts/metadata and regenerate ignored clients rather than hand-maintaining DTOs or paths.
