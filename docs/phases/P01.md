## Implementation plan

1. Bootstrap the smallest pnpm/uv workspace and pin compatible supported tool/generator versions; keep simulator dependencies out of contract/API packages.
2. Implement the canonical status vocabulary, version metadata, success/error envelopes, RunSummary from spec §7.4, and its bounded list response. Defer RunDetail and feature-specific DTOs to their phases.
3. Export deterministic OpenAPI from lightweight route metadata for compatibility metadata and Runs reads, without database/identity/simulator startup or a working business API.
4. Generate the TypeScript Fetch SDK, Zod runtime validators, and TanStack Query options; explicitly enable runtime validation and status-aware error handling.
5. Add minimal schema-valid MSW fixture transport for upcoming UI work and clear generate/check commands. Do not scaffold application UI.
